# 🎓 FutureTech Training Centre System (Java OOP Project)

This is a simple yet fully functional Java application that simulates the operations of a real-world training center. The system is designed using core Object-Oriented Programming (OOP) principles.

---

## 📦 Project Structure

The application is divided into multiple Java classes:
- `Person` – Base class for all people in the system.
- `Student` – Inherits from `Person`, holds course registration.
- `Trainer` – Inherits from `Person`, manages course assignments.
- `Course` – Represents a course with trainer and enrolled students.
- `TrainingCentre` – Manages collections of students, courses, and trainers.
- `Main` – The entry point containing logic and interaction with the user.

---

## 🚀 Features

- View full details of the training center (students, courses, trainers).
- **Search for students or courses by ID**.
- **View all courses registered by a specific student**.
- **Remove a student or a course by ID**.
- Fully interactive console-based menu.
